Things I've built

Enterprise web applications

Business applications built with Java Spring Boot and Angular, secured with Keycloak (SSO, roles and permissions) and connected through REST APIs and RabbitMQ.

Admin dashboards & internal tools

Clean, responsive dashboards and back-office tools in Angular or React that help teams manage users, data and day-to-day operations.

Reporting & automation

Report generation with Spring Boot and Thymeleaf, plus Python and shell scripts that turn manual, repetitive work into reliable background jobs.

Data migrations & deployments

Legacy-to-modern data migrations across PostgreSQL, Oracle and SQL Server, and production deployments on Linux servers with Docker and Nginx.
